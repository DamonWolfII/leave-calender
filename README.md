# Leave Calendar

Next.js (App Router) + TypeScript + Tailwind v4 + shadcn/ui.

```bash
npm install
npm run dev     # http://localhost:3000
```

Mark dates as Leave or Half day, then save as `.txt` (Notepad), `.doc` (Word), copy, or print.
Marks are stored in your browser (localStorage). Add more shadcn components with `npx shadcn@latest add <name>`.
